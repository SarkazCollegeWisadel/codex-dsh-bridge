# 能力边界与非目标

## 已有机制的实际限制

- **本机可信进程模型**：CLI/MCP 与 DSH 使用同一私域目录。不是多租户服务，没有网络认证、端到端加密或数据库加密。能访问这些文件的本地进程可能读写消息；MCP 客户端可以操作该库的全部绑定，route 不是 OS 隔离边界。
- **有限筛查**：代码只筛部分字符串模式、扩展名、大小和路径。classification 是调用方声明，不是脱敏证明；可漏报、误报，不能检测全部个人信息、提示注入或编码密钥。资料上传前必须审阅。
- **权限约定**：user-approved 字符串与 businessPaused 是调用契约，不能验证真实人类同意。允许 MCP/CLI 的操作者须可信。业务动作和提示内容要由执行 Agent 再核用户授权。
- **投递不等于执行**：本地 messageId 幂等、事务和租约降低重复风险；跨宿主中断不能保证业务严格一次执行。执行动作自身也要幂等。unknown 需要真实回执核对，不承诺无人值守自动判定。
- **实验桌面路径**：只提供 Windows 适配，依赖实验 RPC/URI/安装布局。接口变化可能停投；不提供 macOS/Linux 自动唤醒承诺。桌面/DSH 关闭、电脑睡眠或配额耗尽时不会继续推理。
- **事件恢复**：用文件事件而非定时模型保活。文件通知、进程崩溃或权限异常可能需要显式重启 worker/核对状态；没有实时延迟 SLA。
- **旧队列清理**：DSH 侧只清理可识别且正文仍匹配的桥投递项，保留用户编辑项。Codex 侧当前按原生 queue ID 与 client ID 清理已确认或已替代的桥唤醒项，没有正文编辑检测；不要在这些自动生成的唤醒项上附加人工任务，应另发用户消息。无法清理时必须依 current/actionable 阻止旧任务执行。
- **资料引用**：仅限共享 artifacts 下的文本，按 SHA 验证；不是通用文件同步。DSH send 工具目前提交正文，不直接支持 artifactRefs 参数；可提交获准的技术文件标识，由 Codex 在授权范围内独立核验，不能用指向私域原件的路径冒充脱敏附件。
- **历史访问**：正常协作不读取历史正文。宿主 list 可能返回投影，适配仅选取绑定元数据、不持久化投影；高级 successor 工具会流式解压指定文件头，可能缓冲同一压缩块的字节，但只解析首行会话元数据。
- **验证范围**：合成测试覆盖协议恢复，不代表所有 DSH/Codex 版本、安装形态或生产业务已通过。参见 VALIDATION。

## 项目明确不自动承担的工作

自动创建/合并/删除/归档聊天，自动按标题迁移会话；账号迁移或人格提示词审阅；替换用户模型、权限、Plan/Goal 设置；无明确授权的生产部署、收费调用、模型启停、对外发布；历史数据库整库回滚覆盖新任务；无限互相确认或定时消耗 token；宣称模型已经自我训练、所有项目质量有保证或审阅可替代真实验收。

这些边界描述本项目提供的默认实现与 Agent 行为，不是 MIT 许可证之外的用途限制。
